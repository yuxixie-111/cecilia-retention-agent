# Save desk queue rules

- Rank with save priority only when lapse probability, revenue at risk, and days to renewal are all present.
- A larger account with a later renewal can outrank a tiny account that renews this week. Say that explicitly when it happens.
- `call_today` is a scheduling lane, not permission to offer a discount.
- Approval is required before any price change, seat reduction, or message that commits the company to a save offer.
